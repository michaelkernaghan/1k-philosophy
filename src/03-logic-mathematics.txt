Logic :: The study of correct inference, concerned with what follows from what and what makes an argument valid.
Validity :: A property of arguments whose conclusion cannot be false if the premises are true.
Soundness :: A valid argument with true premises, which therefore guarantees a true conclusion.
Deduction :: Reasoning in which the conclusion follows necessarily from the premises, as opposed to induction or abduction.
Syllogism :: Aristotle's form of deduction with two premises and a conclusion, such as "all men are mortal; Socrates is a man; so Socrates is mortal".
Law of Non-Contradiction :: The principle that a proposition and its negation cannot both be true in the same respect, which Aristotle called the firmest of principles.
Law of Excluded Middle :: The principle that every proposition is either true or false, rejected in intuitionistic logic.
Law of Identity :: The principle that each thing is identical with itself, the third traditional law of thought.
Propositional Logic :: The logic of sentences combined by connectives such as "and", "or", "not" and "if", independent of their internal structure.
Predicate Logic :: First-order logic, which adds quantifiers and predicates and can express general claims about objects.
Quantifiers :: Expressions such as "all" and "some" that state how many things satisfy a condition, formalised by Frege.
Material Implication :: The truth-functional "if... then" of classical logic, true whenever the antecedent is false, which gives rise to its paradoxes.
Paradoxes of Material Implication :: The oddities that a false statement implies anything and a true one is implied by anything, which motivate relevance logic.
Modal Logic :: The logic of necessity and possibility, given its modern form by C. I. Lewis and Kripke's possible-worlds semantics.
Possible-Worlds Semantics :: Kripke's account of modal truth, on which necessity is truth in all accessible worlds.
Intuitionistic Logic :: Brouwer's constructive logic, which rejects excluded middle and requires that existence claims be backed by a construction.
Constructivism :: The view that mathematical objects exist only if they can be constructed, with truth tied to proof.
Relevance Logic :: A family of logics requiring the premises of a valid argument to be relevant to its conclusion.
Paraconsistent Logic :: Logics that tolerate contradictions without collapsing into triviality, so that not everything follows from a contradiction.
Dialetheism :: Graham Priest's view that some contradictions are true, motivated by the semantic paradoxes.
Many-Valued Logic :: Logics, beginning with Łukasiewicz, that allow truth values beyond true and false.
Fuzzy Logic :: A many-valued approach in which truth comes in degrees, applied to vagueness and to engineering.
Free Logic :: Logic that allows terms that do not refer, avoiding commitments to the existence of what names denote.
Second-Order Logic :: Logic that quantifies over properties and relations as well as individuals, more expressive but lacking a complete proof system.
Completeness Theorem :: Gödel's 1929 result that every valid sentence of first-order logic can be proved.
Incompleteness Theorems :: Gödel's 1931 results that any consistent, sufficiently strong formal system contains true statements it cannot prove and cannot prove its own consistency.
Decidability :: Whether there is an algorithm that settles for every input whether a statement is a theorem; Church and Turing showed first-order logic is undecidable.
Halting Problem :: Turing's proof that no general algorithm can decide whether an arbitrary program halts.
Church-Turing Thesis :: The claim that whatever is effectively computable is computable by a Turing machine.
Computability :: The study of which functions can be calculated by mechanical procedures, central to logic and the philosophy of mind.
Turing Machine :: Turing's abstract model of computation, a tape and a head following simple rules, which defines what is computable.
Proof Theory :: The study of formal proofs and what they establish, associated with Hilbert and Gentzen.
Model Theory :: The study of the relation between formal languages and the structures that satisfy them.
Tarski's Semantic Conception of Truth :: Tarski's definition of truth for formal languages, with the schema that "snow is white" is true if and only if snow is white.
Liar Paradox :: The sentence "this sentence is false", which is true only if false, and which drives research into truth and self-reference.
Russell's Paradox :: Russell's 1901 discovery that the set of all sets not members of themselves leads to contradiction, undermining naive set theory.
Sorites Paradox :: The paradox of the heap: if removing one grain never turns a heap into a non-heap, then a single grain is a heap.
Epistemicism :: The view that vague predicates have sharp boundaries that we cannot know, defended by Williamson.
Supervaluationism :: An approach to vagueness on which a sentence is true if true on every acceptable way of sharpening its terms.
Paradoxes of Zeno :: Arguments, including Achilles and the Tortoise, that motion and plurality are impossible, which prompted work on infinity and limits.
Infinity :: The notion of the unbounded; philosophers distinguish potential from actual infinity, and Cantor made the latter mathematically respectable.
Actual and Potential Infinity :: Aristotle's distinction between a process that can go on forever and a completed infinite totality.
Set Theory :: The mathematical theory of collections, which Cantor founded and which serves as a foundation for much of mathematics.
Cantor's Theorem :: The proof that no set can be matched one-to-one with its power set, which yields different sizes of infinity.
Continuum Hypothesis :: Cantor's conjecture that there is no infinity between the integers and the reals, shown independent of standard set theory.
Axiom of Choice :: The principle that one can pick an element from each of a collection of non-empty sets, controversial for its non-constructive consequences.
Logicism :: The view of Frege and Russell that mathematics is reducible to logic.
Formalism :: Hilbert's view that mathematics is the manipulation of symbols according to rules, with its meaning found in consistency.
Hilbert's Program :: Hilbert's project of founding mathematics on finitary consistency proofs, undermined by Gödel's second theorem.
Intuitionism :: Brouwer's philosophy of mathematics as mental construction, with truth requiring proof rather than correspondence.
Mathematical Platonism :: The view that mathematical objects are real, abstract and mind-independent, and that we discover rather than invent mathematics.
Structuralism in Mathematics :: The view that mathematics studies structures and positions within them rather than objects with intrinsic natures.
Benacerraf's Dilemma :: The tension between a plausible semantics for mathematics, which requires abstract objects, and a plausible epistemology, which requires causal contact.
Indispensability Argument :: Quine and Putnam's argument that we should believe in mathematical objects because science cannot do without them.
Number :: The nature of numbers, treated by Frege as logical objects, by Dedekind as structures, and by Kant as given in intuition.
Frege's Puzzle :: The problem of how "a = b" can be informative though a and b name the same thing, which led Frege to the distinction of sense and reference.
Peano Axioms :: A short set of axioms for the natural numbers, including induction, that characterise arithmetic.
Mathematical Induction :: A proof technique showing that a property holds for all natural numbers if it holds for zero and passes from each number to the next.
Axioms :: Basic statements taken as starting points of a theory, whether as self-evident truths or as stipulations.
Geometry and Non-Euclidean Geometry :: The discovery of consistent geometries denying the parallel postulate, which forced a rethinking of whether space is Euclidean.
Probability :: The study of chance and degrees of belief, whose interpretations include frequency, propensity and subjective credence.
Subjective Probability :: The view that probabilities are degrees of belief constrained only by coherence, defended by Ramsey and de Finetti.
Dutch Book Argument :: The argument that credences violating probability axioms make an agent open to a sure loss in betting.
Decision Theory :: The theory of rational choice under uncertainty, centred on maximising expected utility.
Newcomb's Problem :: A decision puzzle that pits expected-utility reasoning against dominance reasoning when a predictor knows your choice.
Game Theory :: The mathematical study of strategic interaction, which philosophers apply to ethics, convention and social contracts.
Prisoner's Dilemma :: A game in which individually rational choices produce a collectively worse outcome, used to model cooperation and the state of nature.
Social Choice Theory :: The study of how to aggregate individual preferences into collective decisions, with Arrow's theorem showing limits on fair procedures.
Arrow's Impossibility Theorem :: The result that no ranked voting system with several options can satisfy a set of basic fairness conditions.
Fallacy :: A common error in reasoning, such as the ad hominem, the straw man or begging the question.
Begging the Question :: The fallacy of assuming in the premises what the argument claims to prove.
Ad Hominem :: The fallacy of attacking a person rather than the argument that person offers.
Reductio ad Absurdum :: A form of argument that refutes a claim by deriving a contradiction or absurdity from it.
Dialectic :: A method of argument by question, answer and contradiction; Socrates, Hegel and Marx each gave it a distinct role.
Hegelian Dialectic :: Hegel's pattern of development in which a thesis generates its opposite and both are overcome in a higher synthesis.
Conditionals :: Sentences of the form "if A then B", whose logic and truth conditions are disputed among material, strict and probabilistic accounts.
Counterfactual Logic :: The logic of "if it had been the case that A, it would have been B", analysed with similarity among possible worlds.
Deontic Logic :: The logic of obligation and permission, which formalises what ought to be the case.
Epistemic Logic :: The logic of knowledge and belief, which formalises principles such as the closure of knowledge.
Temporal Logic :: The logic of reasoning about time, developed by Arthur Prior with operators for past and future.
Logical Consequence :: The relation between premises and what follows from them, understood by Tarski in terms of truth preservation across interpretations.
Logical Form :: The underlying structure of a sentence revealed by formalisation, central to Russell's and Frege's approaches.
Logical Pluralism :: The view that more than one logic can be correct, depending on the purposes or notion of consequence at stake.
Logical Positivism :: The Vienna Circle's programme of using logic and empirical verification to dissolve metaphysical questions.
Principia Mathematica :: Whitehead and Russell's attempt to derive mathematics from logic using a theory of types.
Theory of Types :: Russell's hierarchy of entities designed to block paradoxes by forbidding self-referential sets.
Category Theory :: A branch of mathematics that studies structures and the mappings between them, proposed by some as an alternative foundation to set theory.
